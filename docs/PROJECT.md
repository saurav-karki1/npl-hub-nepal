# NPL Hub Nepal

## Project Overview

NPL Hub Nepal is an independent information website focused on the Nepal Premier League (NPL).

The website will provide useful and regularly updated information about NPL matches, teams, players, schedules, results, points tables, statistics, news, tickets, and where to watch.

The website is **not an official website of the Nepal Premier League or Cricket Association of Nepal (CAN)**.

## Main Goal

Build a fast, modern, mobile-friendly NPL information platform that is useful to cricket fans and can attract organic search traffic.

## Target Users

* Nepal Premier League fans
* Cricket viewers
* People searching for NPL schedules and results
* People looking for teams and player information
* People searching for NPL statistics and news

## Core Features

* Homepage dashboard
* Match schedule
* Upcoming matches

* Points table
* Teams and squads
* Player profiles

## Design Direction

The website should look like a professional sports-media platform.

Prefer:

* Strong typography
* Clear information hierarchy
* Cricket/sports imagery
* Scoreboards and tables
* Clean match cards
* Good information density
* Mobile-first responsive layouts
* Restrained and consistent colors

Avoid:

* Excessive gradients
* Excessive rounded cards
* Glassmorphism
* Unnecessary animations
* Generic SaaS dashboard designs
* Decorative elements without a purpose

## Data Rules

Never invent:

* Match dates
* Match results
* Player statistics
* Team information
* Ticket prices
* Broadcasting information
* News

Data must be verified before being displayed.

## Development Principles

* Preserve existing working code.
* Make the smallest reasonable change for small tasks.
* Do not introduce unnecessary dependencies.
* Keep the website fast and responsive.
* Follow good SEO practices.
* Maintain accessibility.
* Test pages visually after major UI changes.
* Do not rewrite unrelated parts of the project.

## Development Strategy

Build the project in stages:

1. Project foundation
2. Design system
3. Homepage
4. Static NPL pages
5. Match and team data structure
6. SEO optimization
7. Database integration
8. Admin system
9. Live tournament features
10. Performance and final polish
