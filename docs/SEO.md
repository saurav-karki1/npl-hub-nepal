# NPL Hub Nepal — SEO Strategy

## Goal

Build NPL Hub Nepal so that its pages can be easily discovered, crawled, understood, and indexed by search engines.

SEO should be implemented as part of development, not added at the end.

## Target Topics

The website should naturally cover searches related to:

* Nepal Premier League
* NPL 2026
* NPL Season 3
* NPL schedule
* NPL matches
* NPL points table
* NPL teams
* NPL players
* NPL results
* NPL statistics
* NPL news
* NPL tickets
* Where to watch NPL

Do not force keywords unnaturally into content.

## Page Titles

Every important page must have a unique and descriptive title.

Examples:

* NPL 2026 Schedule & Matches | NPL Hub Nepal
* NPL 2026 Points Table | NPL Hub Nepal
* NPL 2026 Teams & Squads | NPL Hub Nepal
* NPL 2026 Players & Statistics | NPL Hub Nepal

Titles should accurately describe the page.

## Meta Descriptions

Important pages should have unique meta descriptions.

Descriptions should:

* Clearly explain the page
* Contain relevant search terms naturally
* Encourage useful clicks
* Avoid keyword stuffing

## URLs

Use short, readable URLs.

Examples:

```text
/schedule
/points-table
/teams
/players
/stats
/news
/results
/matches
```

Dynamic pages should use readable identifiers or slugs.

Example:

```text
/teams/[team-id]
/players/[player-id]
/news/[article-slug]
/matches/[match-id]
```

Avoid unnecessary query parameters for primary content pages.

## Heading Structure

Each page should have:

* One clear H1
* Logical H2 sections
* H3 headings where necessary

Headings should describe actual content.

Do not use headings only for visual styling.

## Internal Linking

Important pages should be connected through internal links.

Examples:

* Match → Team
* Match → Player
* Team → Players
* Player → Team
* News → Match
* Homepage → Schedule
* Homepage → Points Table

Use descriptive link text.

## Structured Data

Use appropriate Schema.org structured data where useful.

Possible types include:

* SportsEvent
* Article
* BreadcrumbList
* Organization

Structured data must represent actual visible page information.

Do not create fake or misleading structured data.

## Sitemap

Create an XML sitemap for important indexable pages.

The sitemap should be updated when new dynamic content is added.

## Robots

Provide an appropriate `robots.txt`.

Do not accidentally block important pages or assets from search engines.

## Canonical URLs

Use canonical URLs where necessary to prevent duplicate URL versions from competing with each other.

## Images

Images should:

* Have descriptive filenames
* Use meaningful alt text
* Be optimized
* Use appropriate dimensions
* Avoid unnecessary file sizes

Do not stuff keywords into alt text.

## Performance

SEO and performance should be considered together.

Prioritize:

* Fast page loading
* Optimized images
* Minimal unnecessary JavaScript
* Good Core Web Vitals
* Mobile performance

## Mobile SEO

The website must work properly on mobile devices.

Important content and links must remain accessible on small screens.

## Content Quality

NPL Hub Nepal should provide useful original information.

Do not:

* Copy articles from other websites
* Automatically rewrite existing articles without adding value
* Invent statistics
* Invent news
* Publish unverified information
* Create pages only to target keywords

## Independence

The website must not imply that NPL Hub Nepal is the official NPL or CAN website.

Use clear independent branding and wording.

## Search Console

After deployment:

1. Set up Google Search Console.
2. Verify the website.
3. Submit the XML sitemap.
4. Monitor indexing.
5. Monitor search queries and page performance.

## Analytics

Add analytics only after the core website is working correctly.

Use analytics to understand:

* Traffic
* Popular pages
* Search traffic
* User behavior
* Device usage

## SEO Development Rule

Every new page should be checked for:

* Unique title
* Meta description
* H1
* Clean URL
* Internal links
* Mobile responsiveness
* Image optimization
* Appropriate structured data
* Indexability

SEO must never come at the cost of readability or user experience.
