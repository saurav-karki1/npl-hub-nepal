# NPL Hub Nepal — Design System

## Design Goal

NPL Hub Nepal should look like a professional cricket and sports-media website.

The design should feel:

* Modern
* Clean
* Fast
* Trustworthy
* Information-focused
* Designed for cricket fans

It should not look like a generic AI-generated website.

## Visual Style

Use a sports-editorial design rather than a generic SaaS dashboard.

Prioritize:

* Strong typography
* Clear visual hierarchy
* Match scoreboards
* Tables
* News layouts
* Team and player cards
* Cricket photography
* Clear section headings
* Consistent spacing

## Color Direction

Use a restrained cricket/sports-inspired color palette.

The primary brand color should be consistent throughout the website.

Use accent colors only when they communicate meaning, such as:

* Live status
* Win/loss
* Upcoming match
* Important statistics

Do not use many unrelated colors.

## Typography

Typography should be:

* Highly readable
* Strong for headings
* Clear at small sizes
* Consistent across pages

Use a maximum of a small number of font families.

Avoid decorative fonts.

## Layout

The website should be:

* Mobile-first
* Fully responsive
* Easy to scan
* Well spaced
* Information dense without feeling cluttered

Desktop layouts can use multiple columns where useful.

Mobile layouts should prioritize the most important information first.

## Homepage

The homepage should function as an NPL dashboard.

Recommended order:

1. Header/navigation
2. NPL season hero
3. Next or live match
4. Today's matches
5. Points table preview
6. Latest news
7. Upcoming matches
8. Recent results
9. Top performers
10. Teams
11. Footer

The exact layout can be adjusted during implementation if usability improves.

## Match Cards

Match cards should clearly show:

* Team names
* Team logos
* Match date
* Match time
* Venue
* Match status

For completed matches, show the result.

For live matches, make the live status highly visible.

## Points Table

The points table should prioritize readability.

Important information should remain visible on mobile.

Avoid unnecessarily complicated table designs.

## News

News pages should use an editorial layout.

Use:

* Strong headlines
* Relevant images
* Publication date
* Short summaries
* Clear article hierarchy

Avoid making every article look like a generic rounded card.

## Images

Use relevant cricket/NPL imagery where appropriate.

Images should:

* Have appropriate aspect ratios
* Be optimized for performance
* Include meaningful alt text
* Not be stretched or distorted

Do not use random stock images simply to fill empty space.

## Cards

Cards should be used when they improve information organization.

Avoid excessive use of:

* Large rounded containers
* Glassmorphism
* Floating cards
* Heavy shadows
* Decorative borders

Not every section needs to be inside a card.

## Animation

Animations should be minimal and purposeful.

Use animation only when it improves:

* Feedback
* Navigation
* Loading states
* Live match status

Avoid excessive motion.

## Navigation

Navigation should make important NPL information easy to reach.

Desktop:

* Clear header
* Primary navigation
* Search access

Mobile:

* Compact header
* Mobile navigation
* Easy access to important pages

## Accessibility

The website should maintain:

* Good text contrast
* Keyboard accessibility
* Visible focus states
* Meaningful alt text
* Clear buttons and links
* Readable font sizes

Do not communicate important information using color alone.

## Responsive Design

Test at:

* Mobile
* Tablet
* Laptop
* Large desktop

No important content should be hidden or unusable on smaller screens.

## Performance

Design decisions should support fast loading.

Prefer:

* Optimized images
* Lazy loading where appropriate
* Minimal unnecessary JavaScript
* Reusable components
* Efficient layouts

Avoid heavy visual effects that reduce performance.

## Design Rule

When choosing between a visually impressive design and a clearer, faster, more usable design, prioritize clarity, speed, and usability.

Do not introduce a new visual style on individual pages without a clear reason.
